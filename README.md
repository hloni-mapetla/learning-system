# Loom

A local-first personal learning system: knowledge store + FSRS spaced repetition + to-dos, driven through Claude via MCP.

> Work in progress. The full README (setup, connecting to Claude, backup, remote deployment) lands in Phase 5.

```bash
npm install
npm run build          # build the web UI
npm run serve          # http://127.0.0.1:4317  (DB at ~/.loom/loom.db)
npm test
```
